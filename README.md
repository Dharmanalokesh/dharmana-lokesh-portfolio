## 🚀 Running Locally

### Option 1: Python Built-in Server (Recommended)
Open a terminal in the project directory and run:
```bash
python -m http.server 8080
```
Then visit:
`http://localhost:8080/`

### Option 2: Direct File Opening
Double-click `index.html` to open directly in any browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

## 🌐 Free 1-Click Deployment to GitHub Pages

Since your GitHub profile is `https://github.com/Dharmanalokesh`:

1. Create a new GitHub repository named `dharmana-lokesh-portfolio` or `dharmanalokesh.github.io`.
2. Push this folder to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Dharmana Lokesh Data Analyst Portfolio"
   git branch -M main
   git remote add origin https://github.com/Dharmanalokesh/dharmana-lokesh-portfolio.git
   git push -u origin main
   ```
3. Go to **Settings** > **Pages** in your repository.
4. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
5. Your portfolio will be live at:
   `https://dharmanalokesh.github.io/dharmana-lokesh-portfolio/` (or your root domain).
